Daily Habit Tracker – Project Brief
3 Nov 2026 · @Saksham Garg
Problem statement
I want a simple, minimal daily habit tracker that I can use on my iPhone like a regular app. I want to add my habits, tick them off or add a nuber out of 5 each day, and see  history.
The app is for a single user (me), must keep my data after the app is closed, and must cost nothing to build, host or run. It will be a web app built with plain HTML, CSS and JavaScript, installed on the iPhone Home Screen. All data is stored on the phone, so there is no backend server or external database.
Functional requirements
1. Manage habits: add, edit and delete habits (name, emoji, colour).
2. Today screen: list all habits with a checkbox to mark each one done or not done for today.
3. History: show past completions per habit - a weekly grid.
4. Data persistence: all habits and completions are saved and remain after the app is closed or the phone restarts.
5. Backup: Export all data to a JSON file and Import it back.

Technical decisions
Area
Decision
App type
Progressive Web App (PWA), installed via Safari → Share → Add to Home Screen
Language
Plain HTML, CSS, JavaScript (no framework, no build step)
Storage
IndexedDB on the device (via Dexie.js); localStorage acceptable
Persistence
Call navigator.storage.persist() on startup
Backend
None
External database
None
Offline
Service worker caches app files so it works without internet
Installability
manifest.json with name, icons (192px, 512px), display: standalone
Hosting
Free static hosting with HTTPS: GitHub Pages (or Netlify)
Cost
Free
Constraints and out of scope
Constraints
• Mobile-first, minimal UI designed for iPhone screen sizes; respect iPhone safe areas.
• Simple, readable code that I can maintain myself.
• Data lives only on the device; it is lost if the Home Screen app is deleted or Safari data is cleared, so Export is the backup.
Out of scope for v1
• User accounts or login
• Cloud sync or multiple devices
• Push notifications or reminders
• Native iOS app or App Store release
Deliverables
• index.html, style.css, app.js: the app
• manifest.json: makes the app installable
• sw.js: service worker for offline use
• icon-192.png, icon-512.png: app icons
• Deployed on GitHub Pages and installed on my iPhone Home Screen
